# repor — Informes y Reportes del Proyecto

Esta carpeta contiene los informes y reportes generados para el
**Hotel Posada de la Silleria (Toledo)**.

## Formato

Todos los documentos se almacenan en **PDF** para maximizar la compatibilidad
y facilitar su lectura, impresion y distribucion.

## Convencion de nombres

```
Informe_<tema>_<ano>.pdf       — Informes anuales o periodicos
Reporte_<tema>_<fecha>.pdf     — Reportes especificos o ad-hoc
```

Ejemplos:
- `Informe_Anual_2025_Hotel_Posada_Silleria.pdf`
- `Reporte_Ocupacion_2025-06.pdf`
